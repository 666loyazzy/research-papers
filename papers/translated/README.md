- `*-mono.pdf`：纯中文版
- `*-dual.pdf`：中英双语对照版

- 术语修补：将错误出现的“法学硕士”修正为“大语言模型”
- 说明：机器翻译仅供阅读辅助；引用、数据与结论请以 `papers/original/` 中原文为准。
